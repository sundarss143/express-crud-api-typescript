# Express CRUD API — Node.js + Express + TypeScript

A simple REST API built using Node.js, Express, and TypeScript.  
This project demonstrates CRUD operations using in-memory data storage.

---

## Features

- Express Server Setup
- TypeScript Integration
- REST API CRUD Operations
- Middleware Usage
- Routes & Controllers Structure
- JSON API Responses
- In-Memory Data Storage

---

## Tech Stack

- Node.js
- Express.js
- TypeScript
- ts-node-dev
- CORS
